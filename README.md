# Analizador de Seguridad IDS (Prototipo) 🛡️🤖

Este repositorio contiene un prototipo aislado de un **Sistema de Detección de Intrusos (IDS)** impulsado por Inteligencia Artificial (LLM local). 

## Objetivo
Auditar los logs de tráfico web de `analytics.db` para detectar patrones anómalos, escaneos de bots y ataques directos (SQLi, XSS, Path Traversal) utilizando técnicas de *Few-Shot Prompting*.
